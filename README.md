# Ghada AI Portfolio — WOW FINAL

This version is personalized with the uploaded CV and certificates.

- CV download: `assets/Ghada_CV.pdf`
- 9 certificate PDFs linked in the Certificates section
- GitHub projects
- Responsive mobile/iPhone design
- Dark/light mode
- AI Lab section
- Profile-photo slot

## Add your photo
Place your chosen profile image at `assets/profile.jpg`.

## Add LinkedIn
Replace the two `https://www.linkedin.com/` placeholders in `index.html` with your real LinkedIn URL.

## Run
Double-click `index.html`.

## Publish
Upload `index.html` and the entire `assets` folder to GitHub and enable GitHub Pages.
